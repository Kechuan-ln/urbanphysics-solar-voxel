# urbanphysics-solar-voxel
Interactive annual urban solar radiation voxel visualization

[Open the Kowloon 1 km² demo](https://kechuan-ln.github.io/urbanphysics-solar-voxel/kowloon-light/1km/) to compare three hours on June 21, 2022. The textured scene covers 1 km², with native 5 m sections across the whole square in either orientation and 128 directions per air voxel. GitHub Pages serves all assets.
