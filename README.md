# urbanphysics-solar-voxel
Interactive annual urban solar radiation voxel visualization

[Open the Kowloon 1 km² demo](https://kechuan-ln.github.io/urbanphysics-solar-voxel/kowloon-light/1km/) to compare three hours on June 21, 2022. The textured scene covers 1 km², with a native 5 m section and 128 directions in the 100 × 100 m sample block. GitHub Pages serves all assets.
