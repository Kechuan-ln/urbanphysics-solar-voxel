# urbanphysics-solar-voxel
Interactive annual urban solar radiation voxel visualization

[Open the Kowloon 1 km² demo](https://kechuan-ln.github.io/urbanphysics-solar-voxel/kowloon-light/1km/) to compare three hours on June 21, 2022. The demo opens with 3D volume rendering across the full 1 km². Use a 5 m section or click the volume to read the original 128 directions at an air voxel. GitHub Pages serves all assets.
